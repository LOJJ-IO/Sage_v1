# Troubleshooting

"When X happens, do Y" — playbooks for recurring problems, distinct from [[Lessons-Learned]] (which is *why* it happens) and [[Known-Issues]] (which is *what's currently broken*). This file is for problems that recur and have a known fix, so nobody re-diagnoses from scratch.

## Format
```
### Symptom: <what you observe>
**Likely cause:** ...
**Fix:** ...
**If that doesn't work:** ...
```
