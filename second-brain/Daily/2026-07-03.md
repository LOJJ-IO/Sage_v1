# 2026-07-03 Friday

## Focus
Dark mode, panel empty states, right-panel chat input, and header polish for the app shell.

## Log
- **Dark mode** — `isDark` state toggles `dark` class on `document.documentElement`; sun/moon toggle in global header right group (`837e8335` builds on this).
- **Empty states** — shadcn `Empty` component for left panel (`FilesEmptyState`) and center (`SageEmptyState`); CVA + `components.json` added.
- **Right panel chat input** — `RightPanelChatInput` with rounded pill input, voice + send buttons (UI only, no backend).
- **Global styles** — design tokens in `globals.css` for light/dark; header and panels use `dark:` variants.
- **Header vertical separator (right group)** — commit `837e8335`: added `mx-2 h-5 w-px bg-neutral-200 dark:bg-neutral-700` divider between dark-mode toggle and right sidebar collapse, mirroring the left-group separator after the left sidebar toggle.

## Decisions made
- Header vertical separators use the same token on both sides: light `neutral-200`, dark `neutral-700`.
- Dark mode is client-side class toggle (not system preference yet) — sun/moon in header right group, before the separator + collapse toggle.

## Blockers / open questions
- Empty-state upload button and chat input are UI-only — no backend wiring.
- Dark mode does not yet respect `prefers-color-scheme` or persist to localStorage.
