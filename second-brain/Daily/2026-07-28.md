## Log
- Restored strip `…` settings chrome (Close all unpinned); dividers restyled/aligned in the tab band so they show in light mode.
- Divider next to active tab in light mode: was the shaped tab’s `margin-inline` gutter reading as a line against white chrome, plus fragile `:has([aria-selected])`. Removed side margins; hide via `data-active` on the lane item.
- Overflow: continuous flex-shrink (filename truncates); icon-only only below ~72px measured width. Single ordered tab row; dividers only between tabs (no pinned|unpinned region rule); hover/active hide L+R dividers. Pin and close share one ghost `Button` (same hover bg).
- Overflow under pressure: **compress only** (normal → compact → icon-only, then flex-shrink). No horizontal scrollbar; scroll/pagination overflow modes removed from the strip UI.
- Shortened active/settings tab chrome to `h-9` bottom-aligned; removed inverse bottom fillets (the “curl” scoops) so sides meet the strip line square. See [[Lessons-Learned]].
- Pinned tabs: trailing close ✕ swaps to a pin (click to unpin); dropped the duplicate pin beside the title. Matched pin/close ghost hover; restored strip `border-b` (active tab paints over it so inactive still show the separator).
- Fixed Chrome-style inverse tab fillet clipping: side margin + box-shadow now match `--preview-tab-curve`; removed strip wrapper `overflow-hidden`. See [[Lessons-Learned]].
- Captured preview-tab decisions from design session: explicit duplication only; clicking an already-open file focuses the most recently active matching tab; duplicate instances may share a resource while owning independent view state.
- Locked pinning semantics: pinned tabs stay left, are protected from direct close, survive `close all`, and require explicit unpin before close.
- Locked removed-file behavior: deleted/unavailable files become removed/error tabs instead of auto-closing; removed tabs cannot be duplicated.
- Locked overflow ownership: `pagination` vs `free horizontal scroll` is a tab-strip/workspace preference, persisted via browser storage for MVP; open tabs themselves do not persist across refresh in MVP.

- Locked visual/crowded layout: active tab wider + connected to stage; pinned cluster compresses first with progressive fallback to icon-only then scrollable pinned lane; divider only when pins exist; auto-reveal active pinned tab in scroll fallback.
