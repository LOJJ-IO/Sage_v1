# 2026-07-30 Thursday

## Focus
Fix preview-tab between-tab dividers; ship Phase 9 file viewers.

## Log
- Preview-tab strip: `data-active` was already on lane items, but CSS only hid dividers on hover. Added the two adjacent-sibling rules for `[data-active]` in `preview-tab-chrome.css` so any divider touching the active tab goes transparent.
- **Phase 9 file viewers:** `react-pdf` PDF (page/zoom/scroll), image zoom, txt/md plain text, docx via `/files/{id}/text`; `useDebouncedViewState` + content cache; wired into `PreviewStage`. Tests 73/73; build clean. See [[FEAT-preview-tabs#Phase 9 — File viewers (implemented)]].
- Preview 404 fix: with no `NEXT_PUBLIC_API_URL`, uploads are in-memory (`crypto.randomUUID`) but download hit relative `/files/.../content` on Next → 404. Preview now prefers the library’s local `File` blob; `downloadBackendFile` errors clearly when API URL is unset.
- PDF preview: left-click document toggles `viewState.scrollMode` between `single` and `continuous` (PDF only; not images/text).
- PDF scroll mode: replaced document click with expand-in-place toolbar pill (`PdfScrollModePill`) — closed `[ Single | ▾ ]`, open `[ Continuous | Single | ▴ ]`; Sage tokens for light/dark; labels shortened.
- Settings dialog polish: `size="lg"` (`max-w-2xl`), nav `w-30` with shared `w-24` grid (aligned + centered); shell header `py-3.5` / `space-y-1`, footer `py-3` in `dialog.tsx`. Org dialog `max-w-4xl`.
- Add account → 4-step wizard on `ShellDialog` (shared Settings chrome); `--dialog-shell-*` tokens + `ShellDialog` primitive; `FormDialog`/`ConfirmDialog` compose it.
- Input/Field chrome: dropped stadium radius + shadow; crisp `rounded-lg` fields (`border-foreground/20`, `h-10`). Chat Ask input uses `Input` with `trailing` (same chrome).
- Edit tags → `TagInput` chips; then: no empty-state; wrap chips (no scrollbar); compact shell (`min-h-0`); Save disabled when empty.
- Tag autocomplete: dropped Base UI Popover for a `z-100` body portal under the field — opens on focus with unused library tags, filters as you type.
- All empty states go through `EmptyState` (`ui/empty.tsx`) — files, ask, accounts, preview.
- Truncation tokens in `lib/ui/truncate.ts` (`ch` + container `%`); Edit tags filename + chip labels clip with tooltips.
